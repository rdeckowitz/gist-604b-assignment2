# gist-604b-assignment2
GIST 604B Assignment 2: QGIS Desktop GIS Projects

Overview
This repository demonstrates my work done in practicing GIS dataprocessing skills using the desktop QGIS application. This includes applying previous skills to a new software, including cartography, working with projections and coordinate systems, joins and queries, vector and raster analysis, and importing data. 



Software Environment

QGIS Version Desktop 4.2.3

Windows Operating System

Reflection
Learning through hands-on work is most effective, in my opinion. As I worked through these 10 tutorials, I became more familiar with the layout and capabilities of the QGIS program. This was definitely challenging at first, as I had the instinct to find tool in the location they are in ArcGIS Pro, and I had to adjust to finding them in QGIS instead. I was also challenged when I ran into errors, because my previous lack of familiarity with this software made it difficult to troubleshoot without research. However, this also created a great opportunity to practice troubleshooting in unfamiliar software. This assignment included a wide variety of skills that are essential to GIS analysis, and I anticipate that my ability to apply these skills in QGIS will prove useful for quickly processing information without the need for expensive software. These skills are also applicable not just in the professional world as they expand my ability to independently explore GIS data using accessible software.
